## Deskripsi
Program Python untuk membaca, memvalidasi, dan menganalisis
nilai mahasiswa dari file teks. Program menghitung rata-rata,
nilai tertinggi, nilai terendah, serta jumlah mahasiswa yang
lulus dan tidak lulus.

## Fitur
- Membaca data mahasiswa dari file teks.
- Memvalidasi nama dan nilai mahasiswa.
- Menghitung rata-rata nilai.
- Menentukan nilai tertinggi dan terendah.
- Menghitung jumlah mahasiswa yang lulus.
- Menampilkan dan menyimpan laporan.

## Struktur Folder
- `data/`: Menyimpan data nilai.
- `src/`: Menyimpan kode program Python.
- `tests/`: Menyimpan skenario pengujian.
- `output/`: Menyimpan hasil laporan.

## Cara Menjalankan
Pastikan Python 3 sudah terpasang.

Jalankan perintah berikut melalui terminal VS Code dari
folder utama proyek:

```bash
python src/main.py
```

## Batas Kelulusan
Mahasiswa dinyatakan lulus jika memperoleh nilai minimal 60.

## Hasil
Laporan ditampilkan di terminal dan disimpan pada file
`output/hasil_analisis.txt`.
