
# Proposal Proyek Akhir
## Sistem Analisis Nilai Mahasiswa

### 1. Latar Belakang
Pengolahan nilai mahasiswa secara manual membutuhkan waktu
dan berisiko menimbulkan kesalahan perhitungan. Oleh karena
itu, diperlukan program Python untuk membantu mengolah dan
menganalisis nilai secara otomatis.

### 2. Rumusan Masalah
1. Bagaimana membaca data nilai dari file teks?
2. Bagaimana menghitung rata-rata dan menentukan nilai
   tertinggi serta terendah?
3. Bagaimana menentukan status kelulusan mahasiswa?
4. Bagaimana menyimpan hasil analisis ke file laporan?

### 3. Tujuan
1. Menerapkan konsep dasar pemrograman Python.
2. Menggunakan fungsi untuk membagi tugas program.
3. Mengolah data menggunakan list dan dictionary.
4. Melakukan validasi input dan penanganan kesalahan.
5. Menghasilkan laporan analisis nilai secara otomatis.

### 4. Metode
Program membaca data dari file teks, memvalidasi nama
dan nilai, melakukan perhitungan, menentukan kelulusan,
kemudian menampilkan dan menyimpan laporan.

### 5. Teknologi
- Bahasa pemrograman: Python 3
- Editor: Visual Studio Code
- Penyimpanan data: File teks
- Pengujian: Test case

### 6. Hasil yang Diharapkan
Program mampu membaca data nilai yang valid, menghitung
statistik nilai, menentukan kelulusan, serta menyimpan
laporan ke dalam folder output.
